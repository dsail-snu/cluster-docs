# 질문과 요청

## 묻기 전에

[자주 묻는 질문과 문제 해결](guide/troubleshooting.md)에 같은 증상이 있는지 먼저 확인해 주세요.

## 물어 주실 때 함께 적어 주시면 좋은 것

- **잡 ID**와 **언제** 일어났는지
- **오류 메시지 그대로** (요약하지 말고 복사)
- **무엇을 시도했는지** (실행한 명령, 바꿔 본 것)

DM 대신 이 채널에 올려 주세요. 클러스터 전체가 멈춘 것 같은 급한 장애는 [[admins]] 멘션으로 알려 주세요.
