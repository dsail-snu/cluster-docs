# AI 코딩 도구 사용을 허용합니다

이제 Claude Code, Codex CLI 같은 AI 코딩 도구로 클러스터 작업을 할 수 있습니다. 단, 에이전트에게
[AI 에이전트 규칙](../../policy/index.md#ai-에이전트-규칙)을 반드시 숙지시켜야 하고, 에이전트가 한 일의
책임은 사용자에게 있습니다.

<!-- more -->

핵심 규칙은 다음과 같습니다. 전체 내용은 규정 페이지를 보세요.

- SSH, 전송 접속 시도는 연속 최대 2회, 1분 이상 간격. 실패하면 멈추고 보고
- 잡을 내기 전에 `sq`로 현황 확인, GPU를 잘게 쪼개지 않는 크기로 제출
- GPU 타입 명시, 파티션과 CPU와 메모리 지정 금지, GPU 수는 1, 2, 4, 8
- 상태 조회는 1분 이상 간격, 대량 삭제 같은 작업은 사용자 확인 후 실행
