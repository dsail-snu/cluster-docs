# 노드당 GPU 수는 1, 2, 4, 8로 요청해 주세요

GPU 자원이 잘게 쪼개져 큰 잡이 들어갈 자리가 사라지는 것을 막기 위해, 노드당 GPU 수를 1, 2, 4, 8 중에서
요청하도록 [잡 제출 규칙](../../policy/index.md#잡-제출-규칙)을 바꿨습니다. 곧 스케줄러가 이 규칙을 직접
검사하며, 그 뒤로는 3장, 6장 같은 요청은 제출할 때 거부됩니다.

<!-- more -->

- `--gres=gpu:<GPU 타입>:N`에서 N은 1, 2, 4, 8 중 하나로 적습니다.
- `--gpus=N`처럼 노드 수 없이 총 개수만 적으면 N 자체가 1, 2, 4, 8 중 하나여야 합니다.
- 거부되면 메시지에 가까운 허용값이 나옵니다.
- 검사 적용 날짜는 다시 공지합니다.
