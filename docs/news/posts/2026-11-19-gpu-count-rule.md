# 노드당 GPU 수는 1, 2, 4, 8로 요청해 주세요

- **2026-11-19부터** 노드당 GPU 수는 1, 2, 4, 8 중에서 요청해 주세요 ([잡 제출 규칙](../../policy/index.md#잡-제출-규칙)).
  큰 잡이 들어갈 자리를 남겨 두기 위해서입니다. 곧 스케줄러가 직접 확인해, 3장, 6장 같은 요청은 제출할 때 거절됩니다.

<!-- more -->

- `--gres=gpu:<GPU 타입>:N`에서 N은 1, 2, 4, 8 중 하나로 적어 주세요.
- `--gpus=N`처럼 노드 수 없이 총 개수만 적으실 때는 N 자체가 1, 2, 4, 8 중 하나여야 합니다.
- 거절되면 메시지에 가까운 허용값을 알려 드립니다.
- 확인을 시작하는 날짜는 다시 알려 드리겠습니다.
