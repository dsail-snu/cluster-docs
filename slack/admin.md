# 관리자 채널

[[admins]] 멘션이 달린 글이 처리할 일입니다. 나머지는 기록입니다.

| 글 | 할 일 |
|---|---|
| 알림 (Alertmanager) | 내용의 안내대로 확인. 해결되면 같은 알림에 해결이 올라옴 |
| 승인 대기 신청 (봇) | 버튼으로 승인 또는 거절. 결과는 봇이 신청자에게 DM |
| 새 차단 (봇) | 고정된 차단 목록에 반영됨. 해제는 신청자가 `[[/cluster]] unban` |
| 사용 현황 리포트의 관리자 알림 | 오래 노는 GPU 등, 내용대로 |
| 오늘의 DM 기록 (스레드) | 봇과 도구가 사람에게 보낸 안내. 문의가 오면 여기서 무엇을 받았는지 확인 |

## 고정 메시지

- 지금의 차단 목록 (봇이 고쳐 씀). 그 밖에는 고정하지 않습니다.
