# CPU 스레드 수와 빌드 병렬 수 자동 설정 안내

- **2026-11-26(목)부터**
  - `OMP_NUM_THREADS`, `MAX_JOBS` 같은 변수를 로그인 노드와 잡에서 받은 CPU에 맞게 미리 정해 둡니다.
    로그인 노드에서는 쓸 수 있는 CPU 수, 잡 안에서는 태스크 하나가 받은 CPU 수(빌드 병렬 수는 그 노드에서 잡이 받은 CPU 수)입니다.
  - 잡 스크립트에 직접 적어 두신 값은 그대로 쓰입니다. 따로 바꾸실 것은 없습니다.

<!-- more -->

많은 라이브러리와 빌드 도구(예: PyTorch 확장이나 flash-attn 빌드)는 노드에 달린 CPU 수만큼 스레드를 띄웁니다. 받은 CPU보다
훨씬 많이 띄우게 되어, 로그인 노드가 모두에게 느려지거나 잡이 제 속도를 내지 못했습니다. 정해 두는 변수의 목록은
[CPU 스레드 수와 빌드 병렬 수](../../guide/job-recipes.md#cpu-스레드-수와-빌드-병렬-수)에 있습니다.
