# AI 코딩 도구 사용을 허용합니다

이제 Claude Code, Codex CLI 같은 AI 코딩 도구로 클러스터 작업을 할 수 있습니다. 단, 에이전트에게
[AI 에이전트 규칙](../../policy/ai-agents.md)을 반드시 숙지시켜야 하고, 에이전트가 한 일의
책임은 사용자에게 있습니다.

<!-- more -->

핵심 규칙은 다음과 같습니다. 전체 내용은 [AI 에이전트 규칙](../../policy/ai-agents.md)을 보세요.

- SSH, 전송 접속 시도는 연속 최대 2회, 1분 이상 간격. 실패하면 멈추고 보고
- 잡을 내기 전에 `sq`로 현황 확인, GPU를 잘게 쪼개지 않는 크기로 제출
- GPU 타입 명시, 파티션과 CPU와 메모리 지정 금지, 노드당 GPU 수는 1, 2, 4, 8
- 잡을 기다릴 때는 `sbatch --wait`, 반복 조회는 30초 이상 간격
- `/home`이나 공유 스토리지 전체를 훑는 검색 금지
